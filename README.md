# GeoFrame RAW Assist — UI prototype

旅行写真のJPEG/ARWペアを確認し、類似カットの代表選定とRAW現像候補の判断を支援するローカルUIプロトタイプです。

## 起動

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。配布用の確認は `npm run build` で行えます。

## このプロトタイプで試せること

- 実際のサンプル写真を使った撮影グループの一覧
- 推薦カットと推薦理由、シャープネス・階調・構図スコアの比較
- 別カットへの代表変更
- JPG採用とRAW現像キューへの追加
- 提案、処理待ち、採用済みの表示切り替え
- JPG/ARWフォルダ選択時のファイル数確認

## サンプルデータ

`sample/100MSDCF` には同名のJPG/ARWが281組あります。プロトタイプ表示用には、位置情報などのメタデータを含まない縮小WebPを `public/photos` に生成しています。

## 既知の制限

これは操作と情報設計を検証するフロントエンドプロトタイプです。現在のスコアと推薦理由は画面検証用の固定データで、画像解析・DB保存・ARW現像・ジョブ実行はまだ接続していません。元のJPG/ARWへ書き込む処理はありません。

次の実装段階では、ペアリングとEXIF正規化、画像類似グループ、ルールベース採点を先に接続し、現像エンジンは承認済み候補だけを非同期ジョブとして扱います。
